## Setup

Use Python 3.10+ where compatible with the specific exercise. Some folders may have their own dependencies or setup steps.

```bash
git clone https://github.com/hammadmuntazir/Python-Learning-Journey.git
cd Python-Learning-Journey
python --version
```

Run a script from its own folder, for example:

```bash
python path/to/script.py
```
